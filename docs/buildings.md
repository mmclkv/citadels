# 建筑牌库与规则版本

牌库包含 54 种建筑、92 张牌：54 张普通建筑，30 种新版独特建筑，以及保留的大学、墓地、灯塔、钟楼、舞厅、医院、王座厅。要塞沿用现有两张配置。

新版建筑按 Z-Man 官方《Citadels》规则书（2021 年版权版）处理；旧版专属建筑采用其最后发布的效果。参考：[官方规则书](https://cdn.svc.asmodee.net/production-zman/uploads/2024/10/zc01-rulebook_web.pdf)，[旧版建筑资料](https://play-citadels.online/districts)。不包含非官方自制扩展。

## 已有建筑更新

- 实验室：每回合一次，弃一张手牌得 **2 金**。
- 采石场：可以建造任意数量的同名建筑；行政官、外交官、军务官不能借它取得重复建筑。
- 鬼城：末轮建造也能改变终局颜色；改色后不再算紫色。
- 图书馆：保留领取建筑资源时抽到的所有牌，与天文台组合时保留三张。
- 天文台：费用改为 **4 金**。
- 长城：其他建筑被八号角色操作时费用加 1；外交官交换出去的己方建筑不受己方长城加价。
- 博物馆：交换、抢夺时藏牌随建筑转移；摧毁时藏牌放到牌堆底。

免费建造不会消耗行政官的付费建造没收机会；马厩被没收仍不占建造额度。盗贼巢穴被没收只退实付金币，不退弃牌。法师即时建造使用共同建造流程，保留额外建造额度规则。

## 游戏、训练与兼容性

原生引擎统一负责合法动作、结算与终局分数。训练统计直接采用引擎分数，避免另外一套计分漏掉新增效果。灯塔选牌只对发动者可见，剧院交换不提前公开角色，秘密宝库不通过对手的进行中分数泄露。

现有 entity-v6 权重保持 1790／256 的状态／动作宽度。动作编码 v10 的预留后缀表示新建筑和新效果选择，旧建筑特征保留；历史模型的建筑身份词表仍是 30 种，新建筑使用通用城市属性与新动作特征。当前默认权重能推理，但未训练过这些建筑；后续训练会接触新规则，完整扩展建筑身份词表需要单独的模型版本迁移。

新建筑没有新增主题插画，客户端使用已有无插画牌面回退，展示名称、费用和效果。
