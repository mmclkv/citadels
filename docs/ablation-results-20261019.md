## 解释范围

- 每个开局和被测座位在全部八组重放；同一种子再交换两个被测座位。仅一个席位使用被测网络，其他为固定困难静态启发式电脑。
- 4–8 人均衡，冻结同一策略权重与信念 checkpoint。B 关闭仍保留原生弱规则采样；H 关闭恢复物理分支独立统计；D 关闭为固定 4 粒子。
- CPU 每行动实际总预算相同，包含初始采样/评分。深度上限 2000，访问分布抽样，无根噪声。学习采样不支持的私人响应阶段保留原生路径并统计次数；意外回退使该局失败。
- 置信区间按交换座位的开局对聚类，在各人数层内 bootstrap 10000 次。三项主效应另给 98.33% Bonferroni 区间（summary.json）；交互及组别排序为探索性分析。
- 失败局不算输赢；仅八组和两个座位都完成的匹配块用于因素对照。原始局数和失败均保留，不能只删除某组的不利场次。
- 本实验不是两名网络玩家的相互得分胜负，也不能直接与此前双网络同桌的 100 局相加；它衡量固定对手群下的整桌夺冠能力，不能外推为多人类房间的效果。
- metadata.json 固定完整赛程、权重/程序/源码哈希；games.jsonl 保存逐局数据、开关和运行诊断。

实际平均搜索耗时由总决策耗时除非强制搜索次数估算；强制行动本身耗时很小。单次评估、评分 IPC 和清理不能硬中断，预算并非操作系统硬实时上限。

关闭学习信念时，动态补充把平均世界数从 4 扩大到约 976–985，访问次数反而更多，但夺冠下降。因此不能把问题简单解释成“模拟次数不够”。一个待验证解释是，新世界不断产生新分支，搜索更多停在新叶子的网络评估，缺少对已有分支的深入利用；本轮没有记录路径深度，不能把这个解释当作已证实原因。

历史共享与动态补充有正向交互迹象：第一率交互为 +7.0 个百分点，95% 区间 [+0.5,+13.5]；这是探索性分析，不代表两者同时开启优于全部关闭。其他交互区间跨零。

持续补充的第一率主效应 -11.0 个百分点，在三项主效应的 98.33% Bonferroni 区间 [-19.25,-3.25] 下仍为负。剔除所有涉及补跑的种子对后，752 局原始结果的相应效应为 -8.53 个百分点，95% 区间 [-14.53,-2.56]，方向与结论一致。

## 结论与适用范围

1. 当前这版持续补充隐藏世界在本配置下有明确负收益，应先降低补充速度/上限或改进搜索分配，再重新评测，不能直接视为战力提升。
2. 学习信念的第一率主效应 +3.5 个百分点，95% 区间 [-0.75,+7.75]：有正向迹象，尚不能确认稳定收益。
3. 历史共享的平均效应 -1.0 个百分点，95% 区间 [-5.0,+3.0]：本实验没有确认提升或损害。它修复信息约束的事实与战力效果是两回事。此前双网络同桌的积极结果不能直接泛化到这一套静态 NPC 阵容。
4. 仅开启学习信念的组本次最高，为 24/100；组别排名属于探索性结果，未证明它是普遍最优配置。全开组为 10/100，全部关闭组为 20/100。

补跑收集器初版曾重复写入同一已完成任务；该轮补跑整体中止并单独归档于 ../recovery-aborted-collector/，不纳入任何统计。修正收集器后从头重放全部 24 局，并验证 24 个补跑 ID 和最终 800 个 ID 均唯一。三个日志 I/O 中止和收集器故障均未改变冻结的搜索/决策逻辑或权重。
