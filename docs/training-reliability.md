# 训练可靠性与搜索改进评测

训练控制台默认选择状态 v16（2486 维）与动作协议 v12（448 维）。v12 的动作特征与 v11 相同，版本号用于明确匹配 v16 状态布局。v16 在原有 2054 维之后增加 8×54 个已知手牌计数，按观察者相对座位及建筑种类排列，计数除以 5。只读取本观察者已经知道、仍在持有者手中的卡牌，以及法师当前合法可见的目标手牌。v16 同时把玩家块的原保留槽 18 用于公开的启发式难度（简单 1/3、标准 2/3、困难 1，其他玩家为 0），使价值网络能区分不同强度的已知对手；旧 v14/v15 编码含义不变。

v14/v9、v14/v10、v15/v11 权重可以迁移到 v16/v12。保留已有参数，新增输入列及新启用的难度槽连接权重置零，修正版本头的常数贡献，重置优化器。迁移瞬间输出与旧网络一致；新知识特征需要续训才能被网络利用。历史池也在临时推理副本上迁移，不改写原 checkpoint；旧模型仍可按自身编码直接用于实战。

随机启发式难度现在按每局每席位使用独立随机流选择 easy/normal/hard，开局后保持固定，不改变发牌随机流。训练 NPC 显式关闭额外启发式 MCTS，使困难档使用静态规划，与搜索内部的 NPC 行为保持一致。原生接口 `heuristicMcts.enabled=false` 或 `timeBudgetMs=0` 均可明确禁用启发式搜索。

## 固定整局验证

控制台默认验证容量 32 局、每批额外采集 2 局，可设置验证容量 0 关闭。验证局采用训练种子流中目标训练范围之后的独立区段，运行完整对局，但不增加训练计数、不进入优化样本或回放。每局均匀保留最多 128 条状态，全库最多约 4096 条，以约束存储和评估内存；增加验证局数时相应减少每局状态数。数据保存于 `training-data/validation/fixed-*.json.gz`，恢复相同配置时复用。配置的目标局数、种子、规则引擎、人数、验证容量或编码改变后，会创建不同数据集。

采集期间指标会随样本增加而变化；容量满后冻结。每次参数更新之后只做无梯度前向验证，显示策略 CE/KL、价值 MSE、自身价值 MSE、按人数给出的常数基线，并按人数、早中晚期及观察者类型细分。不同固定数据集的曲线不相连。该验证衡量对冻结轨迹及教师的拟合和校准，不替代第一率评测；轨迹中的真实终局结果对应采集时的行为策略。

## 同桌搜索收益评测

```powershell
.\.python\python.exe -c "import sys,runpy;sys.path.insert(0,'.');sys.argv=['search_gain_eval','--output','test-runs/search-gain','--checkpoint','training-data/你的权重.json.gz','--workers','8'];runpy.run_module('python_backend.search_gain_eval',run_name='__main__')"
```

默认 20 个独立开局，每个开局轮换三次座位，共 60 局；每桌同时放入同一权重的直接策略、500 次搜索、2000 次搜索，其他玩家使用显式关闭搜索的困难静态启发式。三者均按概率抽样、关闭探索噪声，搜索深度 700、初始粒子 8、持续补充开启；信念网络默认跟随 checkpoint 配置，可用 `--no-belief` 关闭。迁移但不追加训练，隔离搜索预算本身的效果。

默认独立采样进程；内存受限可减小 `--workers` 或加 `--threads` 共享 Python。避免同时运行其他大规模多进程回归。`--resume` 复用已完成局，要求权重、二进制及信念权重哈希一致。结果保存源权重和二进制哈希、每局动作统计、第一次数、平分冠军份额、平均名次和同桌两两表现；置信区间按开局整体重采样，保留座位轮换的相关性。搜索中直接策略席位按真实网络抽样；另一搜索席位仍是搜索中的优化玩家近似，评测不宣称精确预测其完整搜索行为。

## 单动作节点连续推进

串行及批量 MCTS 默认在同一次模拟中连续执行内部单动作节点，包括现有对手模型压缩出的单一预测动作，直到新的多动作决策节点、终局或搜索边界。中间节点的唯一动作先验为 1，不再单独调用价值网络或消耗一次模拟；原有节点及各玩家的可见历史仍保留，随机转移也每次重新执行。根节点保留原有估值，以支持零预算结果和跨行动树复用。

每个实际执行的动作仍计入深度上限，循环检测和时间检查继续生效。到达深度上限的单动作节点会获得真实的网络／启发式估值，不回传默认零值；超时未完成的路径不记作访问。C++ `Config.fast_forward_single_actions=false` 可关闭该优化用于消融，默认开启；不改变模型编码，不需要重新训练权重。`expansions` 仍统计所有展开的物理节点，包含未调用网络的单动作节点，不能直接当成网络调用次数。
