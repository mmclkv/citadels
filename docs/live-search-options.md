# 实战搜索时间与高级选项

单人模式和房间的电脑座位默认按搜索时间预算自动搜索。高级选项收起时，旧的手动模拟次数和深度不生效；展开后才应用手动参数，再次收起即恢复自动模式。

策略网络自动模式不估算机器每秒能完成多少次模拟，而是由原生搜索的截止时间控制停止。模拟次数的技术上限为 2147483647，避免原先的 5000 次上限提前结束搜索。深度按 `预算毫秒数 × 0.07` 配置，最小 64、最大 2000；例如 1 秒为 70、10 秒为 700。隐藏信息粒子数保持 4。

启发式电脑继续使用已有的时间预算配置器，收起高级选项时清除手动覆盖。它的深度同样按预算调整，上限为 700。

高级模式同时受时间预算和手动次数上限约束，先达到的条件结束搜索。训练和评测中直接指定的搜索参数保留原有语义。

只有一个合法动作时直接执行，无需等待搜索预算耗尽。

策略网络调试信息包含 `automatic`、`timeBudgetMs`、本次生效的模拟上限与深度，以及实际完成的访问数。
