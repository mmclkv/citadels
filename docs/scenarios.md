# 房间剧本

创建房间、开局前房间设置以及单人设置均可选择“剧本”。默认不使用剧本，保留现有角色组与完整建筑牌组。选择剧本后角色组被禁用；服务器与 C++ 引擎按剧本选角色，不受客户端传来的 `charSetMode` 影响。

提供经典组合、野心勃勃、尔虞我诈、名声显赫、上流社会、加乘效果、心狠手辣。每局保留 54 张普通建筑，加入剧本指定的 14 张独特建筑，每种一张（包括堡垒），共 68 张。结束条件沿用房间设置。

配置来源：https://andyventure.com/boardgame-citadels-scenario/

按照网页角色能力及原版规则交叉核对译名，使用本仓库的稳定 ID。网页的“大教堂”对应独特建筑圣殿（Basilica），而非普通宗教建筑；剧本中的“墓地”对应大墓园（Necropolis）；“避难所”对应秘密宝库（Secret Vault）。网页的住持、修士、主教分别对应本仓库 abbot、monk、bishop，不按英文译名猜测。

人数适配：两人仅用 1～8 号，皇帝固定替换为国王；皇后在三、四人局固定替换为艺术家。经典组合在三人和八人局补入艺术家，其余人数保留八角色；其他剧本三人及以上保留指定九角色。三人九角色选角时，第一轮每人选一张后随机暗置一张，再继续选择第二角色。

剧本定义同时在 `python_backend/catalog.json` 和 `src/cards.js` 中导出；测试校验两端一致。未知剧本由房间入口及原生引擎拒绝。
