# 困难启发式电脑的搜索时间预算

困难启发式搜索以夺冠为主要目标：90% 夺冠收益、10% 名次收益。中途以实力的 softmax（温度 6）估计夺冠机会，重点关注强对手；终局第一名（含并列）为 1，非第一名在 -1 到 -0.8 之间。叶节点评分、rollout 和搜索终局回传统一使用该目标；神经网络价值训练与搜索也使用该终局目标，CFR 训练和评测名次统计仍使用历史名次奖励。

房间仅配置 `heuristicMcts.timeBudgetMs`，单位毫秒，默认 10000，最小 1。
普通行动、选角与接近终局的关键局面使用同一个预算。旧客户端发送的模拟次数、关键局面时间、粒子数等字段均忽略；0 不再表示无限搜索。

实际模拟次数不预估：按机器速度持续模拟，直到预算耗尽。粒子准备、根节点评估、模拟路径、叶节点评分和 rollout 共用从本步决策开始计算的截止时间。模拟路径中也检查超时；未完成的路径不计入访问数。到期即采用已有访问分布，没有完整模拟时使用根先验，不强制补做一次模拟。搜索失败时使用不含额外回合规划的轻量后备策略。单个规则操作不能强制中断，极小预算可能略超时。强制单选直接执行，不必耗尽预算。

对手 rollout 按玩家固定采样贪心、快速建造、高分积累或阻止领先者策略；电脑自己的模拟策略保持贪心。临近终局时额外检查连续建造抢胜和有收益的军事破坏，危险分支最多占 rollout 尾部评估的 25%。额外检查与普通模拟共用原有时间预算，因此同一时间内的模拟次数可能减少；这不是额外延长思考时间。

此预算约束单次 C++ 决策计算，不包含服务器请求排队、网络传输、动画或 `botPace` 的展示延迟；多个房间共用游戏进程时仍可能等待前一个请求完成。

内部自动设置：

| 时间预算 | 粒子数 | 最大深度 | 每叶 rollout 步数 |
|---|---:|---:|---:|
| 小于 1000 ms | 2 | 按 `预算 × 0.07` 计算，范围 64–700 | 4 |
| 1000–4999 ms | 4 | 同上 | 8 |
| 5000–29999 ms | 8 | 同上 | 8 |
| 至少 30000 ms | 16 | 同上 | 8 |

跨行动树复用始终开启，每叶 rollout 一次，`c_puct=1.0` 保持为算法常量，不随时间改变。保留树容量随预算增大：`预算 × 8192 / 10000`，范围 4096–32768，超出时丢弃缓存树，避免无限累积内存。这些范围不是搜索时间的隐藏上限。

服务器默认预算可用 `CITADELS_HEURISTIC_MCTS_TIME_MS` 设置，房间显式预算优先。原来的模拟次数、粒子数、关键局面预算等环境变量不再影响生产搜索。`CITADELS_HEURISTIC_MCTS_ENABLED=0` 仍供诊断关闭搜索。

真实对局与训练 NPC 推进使用同一个 C++ 参数推导和搜索入口。神经网络 MCTS 的参数、网络编码和训练目标不受影响。
