# v0.1.0 — 首个稳定版

游戏与训练代码基于 `945d1b3e90183e9edaf40c16a8dc233019459fa6`（2026-10-10）。
该提交的主要变更是：随机混合阵容自对弈时，仅轮换的训练席位执行完整 MCTS，其他网络对手直接策略推理，策略教师样本仅来自训练席位。

为支持按版本部署，在该基准之上补入版本管理功能：

- `VERSION=0.1.0`、发布标签验证及独立检出/回滚工具。
- `--require-stable` 启动保护，启动信息和 `/api/version` 版本查询。
- 共享训练数据目录配置，GitHub Pages 按稳定版标签发布。

原生规则、建筑牌库、默认模型权重、网络推理代码与训练算法保持基准版本内容。
发布提交的哈希会与基准不同；这是补入发布支持的结果。

部署与回滚步骤见 [版本管理说明](releases.md)。
发布标签不自动切换后端服务器，线上切换需另行执行。
