# 价值评估视角验证（2026-10-28）

## 结论

确认存在根玩家已知信息未进入部分叶节点价值评估的结构性限制；没有发现价值向量的座位旋转错误。本次仅增加可复现诊断测试，未修改生产搜索、权重或训练目标。

搜索世界本身仍然保留根玩家手牌和已观察到的对手手牌；问题发生在**非根玩家行动的非终局叶节点**：神经网络接收该行动玩家的观察，输出所有玩家价值，再旋转座位回传。该观察不一定包含根玩家知道的信息。

## 生产路径

- `native/determinize.hpp::determinize_native_state` 固定观察者自己的手牌、角色以及合法获得的已知牌。
- `native/mcts_core.hpp` 中串行 `expand` 与批量叶节点评估均传入 `node.player`。
- `native/neural_evaluator.hpp::NativeNeuralBatchedEvaluator::evaluate_batch` 按传入玩家分别编码状态和动作；同一请求的策略与价值使用同一状态输入。
- `native/state_features.hpp::encode_known_hands` 只加入当前观察者知道的牌，不向其他玩家泄漏。
- 两种搜索的 `backup` 按叶玩家到目标玩家的相对座位旋转同一预测向量，没有重新按根玩家信息评估价值。
- 终局直接调用 `terminal_value_vector`，不依赖上述非终局预测。

## 实验一：真实状态编码

`native/value_perspective_regression.cpp` 使用生产 `encode_network_state`。覆盖 4、6、8 人和状态编码 v14、v15、v16，共 90 对根玩家手牌对照。对照只将根玩家的一张牌与未观察到的牌库牌交换，保持人数、手牌数量、公共局面和牌堆组成相同。

90 对均满足：根玩家输入不同，另一行动玩家的输入逐元素相同。另验证 v16 下根玩家合法知道的对手牌变化只影响根玩家输入，不影响无此知识的第三方输入。

这是输入级别的不可区分性：对于相同权重、确定性推理和相同叶节点动作输入，价值预测必然相同。该结论不依赖某个检查点训练得好坏；实验未测量旧权重对根视角输入的实际敏感程度。

## 实验二：可精确求解的搜索

使用生产串行、批量 MCTS，批大小 1、8、32，共 16 个案例。构造三玩家两步局面，A 私有信息决定其终局收益为 -0.8 或 +0.8，B 无法观察该信息。评估器使用各自观察下**精确的条件期望**：A 知道自己的收益，B 在对称先验下估计 A 收益为 0。其他两玩家收益固定为 +0.3 和 -0.3，专门检查座位旋转。

- 深度上限 1，在 B 行动的叶节点截断：A 的两种局面均回传 0。
- 深度上限 2，跨过唯一合法后续动作到终局：A 分别回传 -0.8、+0.8。
- 所有情况另外两玩家的 +0.3、-0.3 均正确，访问数也正确。

因此即使评估器没有拟合误差，使用 B 的条件期望也不等于使用 A 已知信息后的条件期望。这个玩具实验验证的是价值信息损失，不是实际游戏战力增益，也不是动作排序反转的测量。

## 边界与下一步

- 无法据此认定这是当前战力停滞的主要原因，也不能量化实战发生比例或夺冠率影响。
- 不同视角预测相同未知信息，本身符合隐私规则。问题在于搜索如何使用这种预测，而不是应让 B 看到 A 的手牌。
- 不能把所有节点的策略和价值整体切换到根玩家视角：对手策略与其决策依据仍须使用对手自己的信息。
- 值得做的下一步是实验性分离策略视角与根收益评估视角，再做同权重、同时间预算的同桌配对比较；仍须保留对手决策语义，并处理根视角也不知道的对手私有信息。
- 如果只尝试对现有网络增加一次根视角价值推理，可先不训练新网络，但额外推理成本和对手私有信息遗漏都必须评估，不能预先保证提升。
